# Дипломный проект: Планировщик задач
Минимальный веб-сервер написанный на Go, реализующий функциональность планировщика задач.

## Возможности проекта
*     Добавить задачу
  
Хранит в себе задачи, каждая из которых содержит дату, заголовок и комментарий к ней.

*     Получить список задач
*     Удалить задачу
*     Получить параметры задачи
*     Изменить параметры задачи
Задачи могу повторяться как ежегодно, так и через заданное количество дней или заданные дни месяца/недели.

*     Отметить задачу как выполненную

Можно отмечать как выполненные в таком случае, задачи без повторения будут удаляться, а с повторением переносятся на следующую дату, что была указана.

## Выполненные задачи по проекту со звездочкой

*     Настройка порта сервера через переменную окруждения TODO_PORT
*     Настройка пути к файлу базы данных через TODO_DBFILE
*     Реализация правил повторения задача по неделям и месяцам
*     Готовый Dockerfile для запуска приложения
## Запуск сервера
1.  Склонируйте репозиторий
```
git clone
```
2.  Перейдите в директорию проекта и запустите сервер в терминале
```
go run .
```
3.  Откройте страницу в браузере по ссылке http://localhost:7540
## Проверка тестами
Для настройки тестов в tests\settings.go должны быть прописаны следующие переменные:
```
var Port = 7540
var DBFile = "../scheduler.db"
var FullNextDate = true
var Search = false
```
Проверка тестами проводится только на запущенном сервере:
```bush
go test ./tests -count=1
```
## Запуск через Docker
1.  Соберите образ:
    ```
    docker build -t go-final .
    ```
2.  Запустите контейнер:
    ```
    docker run -p 7540:7540 
    ```
